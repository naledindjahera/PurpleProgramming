The Twin Sentinels

Branch, build, and answer back — all at once

Def The Trial

Two Sentinels guard the exit of the Branching Paths. They will only lower their spears for a wizard who can wire together conditionals, functions, parameters, and return values in one working program.

1 Challenge 1 · Report Card
  • Write a function grade_learner(name, average) that returns (does not print) a letter grade using the NSSC-style bands: A for 80–100, B for 70–79, C for 60–69, D for 50–59, and F below 50.
  • Write a second function report_line(name, average) that calls grade_learner internally and returns a formatted string like "Helvi: 84 -> A".
  • Create a list called learners of at least 3 (name, average) pairs for learners from different Namibian towns.
  • Loop through the list, call report_line for each learner, and print every line.

2 Challenge 2 · Class Summary
  • Reuse (or rewrite) grade_learner(name, average) and report_line(name, average) exactly as in Challenge 1.
  • Create a list called learners of at least 5 (name, average) pairs.
  • Loop through the list, print report_line for each learner, and use a running counter variable good_count starting at 0 that increases by 1 every time a learner's grade is C or better.
  • After the loop, print a summary sentence with good_count, e.g. "3 out of 5 learners scored C or better."
