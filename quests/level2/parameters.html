Parameters & Arguments

Feeding information into a spell

Def Definition

Parameters are the placeholder names listed in a function's definition that let it accept information from outside. Arguments are the actual values you pass in when you call the function, filling in those parameters.

Passing data into a function 
def describe_trip(town, distance_km, travel_mode="bus"):
    print(f"{town} is {distance_km}km away, travelling by {travel_mode}.")

describe_trip("Rundu", 715)
describe_trip("Luderitz", 340, "car")
1 Challenge 1

Write a function describe_trip(town, distance_km, travel_mode="bus") that prints a sentence in the format: "Rundu is 715km away, travelling by bus." Give travel_mode a default value of "bus". Call the function twice: once giving only town and distance_km (so the default is used), and once overriding travel_mode with a different value like "car".
