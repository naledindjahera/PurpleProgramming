Input & Output

Speaking with the world

Def Definition

Output is how a program shows information using print(). Input lets the program collect information from the user using input() — which always hands back a string, no matter what the user typed.

Collecting and displaying information 
town = input("Which Namibian town are you from? ")
temp_today = input("What is today's temperature in Celsius? ")

print("Hello from " + town + "!")
print("It is " + temp_today + " degrees where you are.")
1 Challenge 1

Write a small check-in program for camp arrivals. Use input() to collect their name into name, their region (e.g. Khomas, Erongo, Oshana) into region, and how many hours they travelled into hours. Print a single welcome message that includes all three pieces of information, then print a second line saying whether they travelled a "short trip" (2 hours or less) or a "long journey" (more than 2 hours) — remember input() always returns text, so it's fine to use int(input(...)) to compare the hours numerically.

2 Challenge 2

Write a farewell program for the last day of camp. Use input() to collect the camper's favourite activity into activity, and how many days they attended into days (converted to a number). Print a farewell message that includes their favourite activity, then print a second line saying whether they were a "weekend camper" (3 days or fewer) or a "full week camper" (more than 3 days).
