The Skeleton Coast Cipher

Two challenges — scrambling letters, then unscrambling them

Challenge 1 · the puzzle 
# Smugglers along the Skeleton Coast send coded telegrams using
# a simple CAESAR CIPHER: every letter is shifted forward N
# places through the alphabet, wrapping from Z back to A. Case
# is preserved, and anything that isn't a letter (spaces,
# punctuation, digits) is left exactly as it is.
#
# Given a message and a shift N, print the encoded telegram.
#
# Input:  Meet at midnight
#         5
# Output: Rjjy fy rnisnlmy
✎ Working it out

For each character, check whether it's a letter. If it is, find its position in the alphabet (0–25), add the shift, wrap around with % 26, then convert back to a letter — using the right base ('A' or 'a') to preserve case. If it isn't a letter, copy it across unchanged.

Python's ord() and chr() functions convert between a character and its numeric code, which is exactly what you need to do the shifting arithmetic.

1 Challenge 1 — Warm-up

Write a program that reads a message (a full line, which may contain spaces and punctuation) and a shift N, then prints the encoded telegram. Preserve uppercase/lowercase, and leave non-letter characters unchanged.

▸ Need a hint?

Loop over the message one character at a time. Use char.isalpha() to test if it's a letter, then pick base = ord('A') or ord('a') depending on char.isupper(). The shifted letter is chr((ord(char) - base + N) % 26 + base). Build up the result with string concatenation, then print it once the loop finishes.

▸ Show solution
message = input()
shift = int(input())

result = ""
for char in message:
    if char.isalpha():
        base = ord('A') if char.isupper() else ord('a')
        result = result + chr((ord(char) - base + shift) % 26 + base)
    else:
        result = result + char

print(result)

1.b  "Zebra", N=1  → Afcsb
1.c  "Hello, World!", N=0  → Hello, World!
1.d  "abcXYZ", N=2  → cdeZAB

2 Challenge 2 — No Solution Given

Write a program that reads an encoded telegram (a full line) and the shift N that was used to encode it, then prints the decoded original message. Decoding shifts letters backward instead of forward — watch out for wrapping past A or a the same way Challenge 1 wrapped past Z or z.

Decoding is the same arithmetic as encoding, just with the shift subtracted instead of added — and Python's % operator already handles negative wraparound correctly, so (ord(char) - base - N) % 26 + base works directly. Alternatively, encoding with a shift of (26 - N) % 26 gets you the same result, if you'd rather reuse your Challenge 1 logic.
