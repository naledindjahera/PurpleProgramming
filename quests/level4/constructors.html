Constructors

Setting up an object the moment it's born

Def Definition

A constructor is the special method __init__ that runs automatically when a new object is created, usually to set its starting values so you don't have to attach them by hand afterwards.

Using __init__ to set starting values 
class Learner:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

l1 = Learner("Tangeni", 11)
print(l1.name, l1.grade)
