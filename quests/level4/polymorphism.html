Polymorphism

One method name, many behaviours

Def Definition

Polymorphism means different classes can share the same method name but have it behave differently for each class — you call the same method, and each object responds in its own way.

The same method name, different behaviour 
class TaxiCombi:
    def travel(self):
        print("The combi weaves through Katutura traffic.")

class GameDrivenTruck:
    def travel(self):
        print("The truck rumbles across the gravel toward Etosha.")

for vehicle in [TaxiCombi(), GameDrivenTruck()]:
    vehicle.travel()   # same method call, different result each time
✕ Challenge

Create three classes — Kapana, Vetkoek, and OshifimaMeal — each with a method called describe() that prints a unique one-line description of that street food. Put one object of each class into a single list, then loop through the list calling .describe() on every object without checking what type each one is — that's polymorphism doing the work for you.

The loop body should be a single line: item.describe(). You should never need an if/elif checking the class type — that's the whole point.
