Encapsulation

Protecting an object's inner workings

Def Definition

Encapsulation means keeping an object's data protected inside the class, usually only letting it change through the class's own methods, instead of being edited directly from outside.

A private attribute with controlled access 
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance   # private (name-mangled)

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

    def get_balance(self):
        return self.__balance

acc = BankAccount(100)
acc.deposit(50)
print(acc.get_balance())   # 150 - accessed only through a method
✕ Challenge

Write a class NamibianWallet with a private attribute __balance set by the constructor. Add a method deposit(amount) that only adds the amount if it's positive, otherwise it prints an error and changes nothing. Add a method withdraw(amount) that only succeeds (and prints "Withdrawal successful") if amount is positive and less than or equal to the current balance, otherwise it prints "Insufficient funds" and changes nothing. Add a method get_balance() that returns the balance. Create one wallet with N$500, then run a deposit of N$120, a failed withdrawal of N$10000, and a successful withdrawal of N$200, printing the balance after each step.

Every method should check its condition before touching self.__balance — that's what makes the data protected rather than just private in name.
