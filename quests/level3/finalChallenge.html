The Vault Warden

Structure your knowledge, or be turned away

Def The Trial

The Vault Warden guards Namibia's ancient census scroll. To pass, a wizard must combine lists, dictionaries, and sets to make sense of messy, real data.

✕ Challenge
  • You're given a list of tuples: records = [("Khomas", "Windhoek"), ("Erongo", "Swakopmund"), ("Khomas", "Rehoboth"), ("Oshana", "Oshakati"), ("Erongo", "Walvis Bay"), ("Khomas", "Windhoek")] pairing a region with a town that reported in (note the duplicate Windhoek entry, and repeated regions).
  • Build a dictionary region_towns where each key is a region and each value is a list of the towns that reported for it, with no duplicate towns inside any list.
  • Print the dictionary so each region shows on its own line as "Khomas: ['Windhoek', 'Rehoboth']".
  • Using a set built from the first elements of records, print how many unique regions reported in total.
  • Find and print the region with the most distinct towns reporting, using the dictionary you built.
Loop through records; for each (region, town) pair, use dict.setdefault(region, []) to get-or-create the list, then only append the town if it isn't already in that list.
