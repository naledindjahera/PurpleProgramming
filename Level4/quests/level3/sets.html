Sets

Collections with no duplicates, no order

Def Definition

A set stores unique values only — adding a duplicate does nothing, and sets support fast operations like union, intersection, and difference for comparing groups.

Set operations 
windhoek_trip = {"Naledi", "Junias", "Helvi", "Tangeni"}
swakop_trip = {"Helvi", "Rauna", "Tangeni", "Meme Ndeshi"}

print(windhoek_trip | swakop_trip)   # union - everyone on either trip
print(windhoek_trip & swakop_trip)   # intersection - on both trips
print(windhoek_trip - swakop_trip)   # difference - only on the Windhoek trip
