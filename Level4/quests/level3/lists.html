Lists

Ordered collections of anything

Def Definition

A list stores many values together in one variable, in order, and lets you add, remove, slice, and loop through them.

Creating and slicing a list 
towns = ["Windhoek", "Swakopmund", "Oshakati", "Rundu", "Keetmanshoop"]

print(towns[0])       # first
print(towns[-1])      # last
print(towns[1:3])     # slice
towns.append("Otjiwarongo")
towns.remove("Rundu")
print(towns)
✕ Challenge

Store the population estimates (in thousands, as ints) of 6 Namibian towns in a list called populations, in the same order as a matching list called towns. Write a program that: (1) prints the town with the largest population using max() and .index(), (2) calculates and prints the total combined population using sum(), (3) calculates and prints the average population rounded to 1 decimal place, (4) uses slicing to print only the last 3 towns in the list.

biggest = max(populations); then towns[populations.index(biggest)] gives you the matching town name, because both lists share the same order.
