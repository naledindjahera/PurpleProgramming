Strings

Sequences of characters

Def Definition

A string is a sequence of characters wrapped in quotes. Because it's a sequence, you can index it, slice it, reverse it, and loop through it just like a list.

Slicing and reversing strings 
word = "oshiwambo"

print(word[::-1])     # reversed
print(word[0], word[-1], word[1:4])
print(len(word))
print(word[::2])      # every second letter
✕ Challenge

Namibia's ISO country code and a national ID both hide structure inside plain text. Write a program that asks the user for a Namibian national ID number as text (format: YYMMDDSSSCC, e.g. "03051200456"). Using slicing, extract and print: (1) the 2-digit birth year, (2) the birth month, (3) the birth day, (4) the gender/sequence digits (positions 7-9), (5) whether the ID reads the same forwards and backwards (a palindrome check using slicing, just for fun, printed as True/False).

Remember string indices start at 0. birth_year = id_number[0:2], birth_month = id_number[2:4], and so on. Palindrome check: id_number == id_number[::-1].
