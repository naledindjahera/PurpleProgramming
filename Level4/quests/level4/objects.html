Objects

Real things made from a blueprint

Def Definition

An object is a specific instance made from a class. Each object is separate from the others, even though they share the same blueprint.

Creating multiple objects from one class 
class TaxiCombi:
    pass

combi_a = TaxiCombi()
combi_b = TaxiCombi()

print(combi_a)
print(combi_b)
print(combi_a is combi_b)   # False - two separate objects
✕ Challenge

Using the Learner class from the last unit, create three separate Learner objects with different variable names. Manually attach a .name attribute to each one after creation (e.g. learner1.name = "Helvi"). Print a sentence for each object using its .name, and print learner1 is learner2 to prove they are different objects even though they came from the same class.

You can attach a new attribute to an object at any time just by assigning to it with dot notation, even outside the class definition.
