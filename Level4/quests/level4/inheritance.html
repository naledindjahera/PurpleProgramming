Inheritance

Building on what already exists

Def Definition

Inheritance lets one class (the child) reuse and build on the properties and methods of another class (the parent), instead of rewriting everything from scratch.

A child class extending a parent class 
class Vehicle:
    def __init__(self, plate):
        self.plate = plate

    def describe(self):
        print(f"Vehicle with plate {self.plate}")

class TaxiCombi(Vehicle):
    def __init__(self, plate, route):
        super().__init__(plate)
        self.route = route

combi = TaxiCombi("N123W", "Katutura -> Town")
combi.describe()
print(combi.route)

Write a parent class SchoolProgram with a constructor storing subject and a method summary() that prints "Subject: {subject}". Write a child class CodingCamp that inherits from SchoolProgram, whose constructor accepts subject and language (calling the parent constructor with super() for the subject part), and overrides summary() to first call the parent's summary() with super().summary() and then print an extra line mentioning the language. Create one CodingCamp object for "Programming" taught in "Python" and call its summary().

super().__init__(subject) hands the subject up to the parent's constructor. super().summary() calls the parent's version of the method before you add your own extra line.
