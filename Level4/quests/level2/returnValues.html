Return Values

Sending an answer back

Def Definition

A return value is the result a function sends back after it runs, using the return keyword, so you can store it in a variable and use it later — unlike print(), which only displays a value and hands nothing back.

return vs print 
def convert_to_percentage(mark, total):
    return round((mark / total) * 100, 1)

score = convert_to_percentage(64, 80)
print(score + 5)   # 85.0  - we can keep calculating with it, because it's a real value
