Methods

Built-in spells that live inside objects

Def Definition

A method is a built-in function that belongs to an object, like a string or a list. You call it using a dot, like text.upper().

String methods in action 
school = "  David Bezuidenhout High School  "

print(school.strip())
print(school.upper())
print(school.lower())
print(school.strip().replace("High School", "SS"))
print(school.strip().count("o"))
