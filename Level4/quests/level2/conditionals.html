Conditional Statements

Choosing which path to take

Def Definition

Conditional statements let your program make decisions and run different code depending on whether something is True or False. Python uses if, elif, and else to branch between paths.

Branching with if / elif / else 
rainfall_mm = 18

if rainfall_mm >= 20:
    print("Good rains — plant the mahangu.")
elif rainfall_mm >= 10:
    print("Light rains — wait a little longer.")
else:
    print("Too dry — hold off planting.")
