Type Casting

Shapeshifting between types

Def Definition

Type casting means converting a value from one data type to another — for example, turning the text "12" that input() gives you into the number 12 so you can do maths with it.

Converting between data types 
price_text = "24.50"
price = float(price_text)      # str -> float
quantity = int("6")            # str -> int
receipt_code = str(404)        # int -> str

print(price * quantity)        # 147.0
print("Order #" + receipt_code)
