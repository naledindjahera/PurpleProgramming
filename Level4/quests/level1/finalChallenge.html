The Crystal Guardian

Every rune you've learned, tested at once

Def The Trial

The Crystal Guardian blocks the path out of Level 1. To get past it, you'll need to combine everything you've learned — variables, data types, operators, input & output, and type casting — into two working programs.

1 Challenge 1 · Class Results
  • Ask for the number of learners who wrote a test (as text) into learners, and the total marks available (as text) into total_marks — convert both to int.
  • Ask for the class average mark (as text) into class_avg, and convert it to float.
  • Calculate the average as a percentage of the total marks, rounded to 1 decimal place, and store it as percentage.
  • Using a comparison operator, check whether the class reached the pass benchmark of 50%, store it as passed, and print it.
  • Using a logical operator, check whether the class both passed and had more than 20 learners write the test, store it as strong_group, and print it.
  • Finish with one printed sentence summarising the result, e.g. "31 learners averaged 64.2% — the class passed."

2 Challenge 2 · Camp Store Weekly Target
  • Ask for the number of items sold this week (as text) into items_sold, and the price of each item (as text) into price_each — convert to int and float.
  • Calculate revenue = items_sold * price_each, rounded to 2 decimal places.
  • Using a comparison operator, check whether revenue reached the weekly target of 500, store it as hit_target, and print it.
  • Using a logical operator, check whether the store both hit the target and sold more than 50 items, store it as big_week, and print it.
  • Finish with one printed sentence that uses type casting to include the revenue, e.g. "Revenue: N$612.5 — target reached."
