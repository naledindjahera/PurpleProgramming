Operators

The art of transformation

Def Definition

Operators perform operations on variables and values. Python has arithmetic (+ - * /), comparison (== < >), and logical (and or not) operators — and floor division // and modulo % for splitting things up cleanly.

Arithmetic, comparison, floor division and modulo 
# Sharing 250 N$ in prize money between 6 campers
prize = 250
campers = 6
print(prize // campers)   # 41  - each camper's whole-number share
print(prize % campers)    # 4   - the leftover that can't be split evenly

x, y = 5, 3
print(x > y and y > 0)    # True
print(x == y or y < 10)   # True
