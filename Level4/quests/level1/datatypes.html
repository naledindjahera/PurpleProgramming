Data Types

The four elements of data

Def Definition

A data type describes what kind of value a variable holds. Python has four fundamental types: integers, floats, strings, and booleans. The Ministry of Home Affairs registry in Windhoek stores millions of records — and every single field on that form is really just one of these four types in disguise.

The four core data types 
id_number = "97031000123"    # str  - stored as text, has leading structure
age = 27                     # int  - whole number
height_m = 1.68              # float - decimal number
has_voted = True             # bool - True or False

print(type(id_number))
print(type(age))
print(type(height_m))
print(type(has_voted))
