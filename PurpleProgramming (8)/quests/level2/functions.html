Functions

Spells you can cast again and again

Def Definition

A function is a named block of code that performs a task and can be reused whenever you need it. You define it once with def and call it by name.

Defining and calling a function 
def greet_camper():
    print("Welcome to Purple Programming Camp!")

greet_camper()
greet_camper()   # reused a second time, no need to rewrite it
1 Challenge 1

Write a function called greet_camper that takes no parameters and prints "Welcome to Purple Programming Camp!". Call the function twice to prove it can be reused.

2 Challenge 2

Write a function called fuel_estimate that (with no parameters) asks the user for the distance in kilometres from Windhoek to their destination, stores it in distance, and prints an estimated fuel cost, assuming the car uses 8 litres per 100km and fuel costs N$21.50 per litre. Call the function twice to show it can be reused for two different trips (e.g. Windhoek to Swakopmund, then Windhoek to Katima Mulilo).
