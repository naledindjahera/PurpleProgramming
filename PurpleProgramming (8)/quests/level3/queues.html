Queues

First in, first out

Def Definition

A queue stores items so the first one added is the first one removed — FIFO, First In First Out — like the line at Shoprite on a Friday afternoon. Python's collections.deque gives fast queue operations.

Using deque as a queue 
from collections import deque

till_queue = deque()
till_queue.append("Customer A")
till_queue.append("Customer B")
till_queue.append("Customer C")

print(till_queue.popleft())   # first one in is served first
print(till_queue)
