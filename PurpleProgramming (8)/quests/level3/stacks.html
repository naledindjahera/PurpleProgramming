Stacks

Last in, first out

Def Definition

A stack stores items so the last one added is the first one removed — LIFO, Last In First Out — like a stack of enamel plates at a braai. Python lists give you this for free with .append() and .pop().

Using a list as a stack 
undo_stack = []
undo_stack.append("typed hello")
undo_stack.append("typed world")
undo_stack.append("deleted a line")

print(undo_stack.pop())   # undoes the most recent action first
print(undo_stack)
