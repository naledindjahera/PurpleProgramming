Dictionaries

Looking things up by name, not number

Def Definition

A dictionary stores data as key: value pairs, so instead of looking something up by position (like a list), you look it up by name.

Building and reading a dictionary 
regions = {
    "Khomas": "Windhoek",
    "Erongo": "Swakopmund",
    "Oshana": "Oshakati",
}

print(regions["Khomas"])
regions["Zambezi"] = "Katima Mulilo"
print(regions.get("Kavango East", "Unknown region"))

for region, capital in regions.items():
    print(region, "->", capital)
✕ Challenge

Build a dictionary called menu for a camp tuck-shop where each key is a food item (str) and each value is its price in N$ (float) — include at least 5 items (e.g. "vetkoek", "fat cake", "kapana"). Then: (1) ask the user to type an item name and print its price using .get() with a fallback message if it isn't on the menu, (2) add one new item to the dictionary after it's created, (3) loop through the whole menu and print every item with its price formatted as "Item: N$Price", (4) print the total value of the whole menu using sum() on .values().

menu.get(item, None) returns None if the key is missing — check that first before deciding what to print. sum(menu.values()) adds up every price in one line.
