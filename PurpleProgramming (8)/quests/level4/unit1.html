The Namib Mosaic

Two challenges — no new syntax, just clear thinking

Challenge 1 · the puzzle 
# A guesthouse in Lüderitz tiles its courtyard floor in a
# repeating pattern of terracotta and cream tiles — like a
# giant chessboard. The courtyard is always a square, S tiles
# by S tiles, and by tradition the top-right tile is always
# terracotta.
#
# Given S, how many terracotta tiles does the courtyard have?
#
# Input: 4    Output: 8
# Input: 7    Output: 25
✎ Working it out

When S is even, the two colours split the courtyard exactly evenly, so terracotta tiles = S² ÷ 2. For S = 4: 16 ÷ 2 = 8.

When S is odd, the tiles can't split evenly — one colour gets exactly one extra tile. Since the top-right tile is always terracotta, terracotta gets that extra tile: (S² + 1) ÷ 2. For S = 7: (49 + 1) ÷ 2 = 25.

1 Challenge 1 — Warm-up

Write a program that reads the courtyard's side length side as an integer, then prints the number of terracotta tiles. Handle both even and odd side lengths correctly.

▸ Need a hint?

Use side % 2 to check whether the side length is odd. If it's odd, add 1 before dividing by 2 (or use integer division // so the extra tile isn't dropped).

▸ Show solution
side = int(input())

if side % 2 == 0:
    print(side * side // 2)
else:
    print((side * side + 1) // 2)
Try these side lengths and check your output matches:
1.a  S=4  → 8
1.b  S=7  → 25
1.c  S=1  → 1
1.d  S=10 → 50
Challenge 2 · the puzzle 
# The guesthouse next door has a RECTANGULAR courtyard —
# width W tiles and height H tiles — tiled with the same
# purple/violet checkerboard pattern. As always, the
# top-right tile is purple.
#
# Given W and H, how many purple tiles are there?
#
# Input: 5 3   Output: 8
2 Challenge 2 — No Solution Given

Write a program that reads two integers, the width W and height H of the courtyard (on one line, space-separated, or on two lines — your choice), and prints the number of purple tiles. This time the courtyard isn't a square, so the neat "÷2" trick from Challenge 1 won't directly apply — you'll need to reason about which tiles are actually purple.

Number the columns 1..W and the rows 1..H. The top-right tile is at row 1, column W, and it's purple. A tile at (row, col) is the same colour as the top-right tile exactly when (row + col) % 2 == (1 + W) % 2. Loop over every row and column, count the matches — that's your purple total. (There's also a closed-form formula if you'd rather work it out on paper, but the double loop is the most reliable way to get it right.)

Try these width/height pairs and check your output matches:
2.a  W=4, H=6  → 12
2.b  W=6, H=5  → 15
2.c  W=9, H=9  → 41
2.d  W=10, H=7 → 35
